# 🎲 Pig Game

A fun and interactive two-player Pig Dice Game built using **HTML, CSS, and JavaScript**. Roll the dice, accumulate points, and hold your score strategically to reach the winning target before your opponent!

The game features a responsive design, customizable winning scores, dice roll history, and sound effects.

## 📸 Features

- 🎲 **Dice Rolling:** Roll a dice to accumulate points.
- 👥 **Two-Player Mode:** Take turns playing against another player.
- 🏆 **Custom Winning Score:** Choose between 50, 100, 150, and 200 points.
- 📜 **Dice Roll History:** Track the last five dice rolls.
- 🔊 **Sound Effects:** Enable or disable game sounds.
- 📱 **Responsive Design:** Play on desktop, tablet, and mobile devices.
- 🔄 **New Game:** Restart the game whenever you want.

## 🎮 Game Rules

1. Two players take turns rolling a dice.
2. Each roll (except 1) adds points to the player's current score.
3. If a player rolls a **1**, their current score becomes zero, and their turn ends.
4. A player can select **Hold** to add their current score to their total score and pass the turn.
5. The first player to reach the selected winning score wins the game.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling, Flexbox, and responsive design.
- **JavaScript (ES6+)** – Game logic, DOM manipulation, and event handling.
